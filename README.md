# App Store / Google Play Reviews Downloader

Telegram-бот и консольные скрипты скачивают отзывы App Store и Google Play. Бот и интерактивный CLI сохраняют Markdown, массовая выгрузка — JSON/CSV.

## Возможности

- Telegram-бот:
  - определяет магазин по ссылке
  - после ссылки предлагает «Скачать все отзывы»: все страны, языки и оценки
  - «Настроить» позволяет независимо ограничить страну, язык Google Play или оценку
  - обходит публичное RSS-API Apple или веб-выдачу Google Play, удаляет дубликаты по ID
  - формирует `.md` файл и отправляет его в чат
  - во время скачивания остаётся отзывчивым
  - каждая выгрузка использует отдельную временную папку, которая удаляется после отправки или ошибки
  - показывает прогресс; `/stop` останавливает сбор с выдачей уже полученных отзывов
- CLI-скрипт (`ratings.py`):
  - распознаёт магазин по ссылке и сохраняет отзывы в Markdown
  - для Google Play позволяет выбрать страну, язык и оценку
- Массовая выгрузка (`bulk_reviews.py`): несколько приложений и стран в JSON/CSV

## Формат выходного файла

Файл создаётся по шаблону:

`{app_id}_reviews_{country.lower()}_{rating_input}.md`

Примеры:

- `1195601592_reviews_us_all.md`
- `1195601592_reviews_ru_5.md`

`rating_input`:
- `1..5` — только отзывы с этой оценкой
- `all` — все оценки

Для Google Play: `googleplay_{package_id}_reviews_{country}_{lang}_{rating}.md`.
Например: `googleplay_com.duolingo_reviews_us_en_1.md`.

## Структура проекта

- `appstore_reviews.py` — ядро: скачивание отзывов и генерация `.md`
- `googleplay_reviews.py` — загрузка отзывов Google Play, пагинация и генерация `.md`
- `bulk_reviews.py` — массовая выгрузка в JSON/CSV
- `bot.py` — Telegram-бот (polling)
- `review_archive.py` — сбор по сетке стран/языков для бота, дедупликация и отчёт об охвате
- `store_locales.json` — каталог стран и языков с датой обновления и ссылками на источники
- `ratings.py` — CLI-версия
- `requirements.txt` — зависимости
- `.env` — токен бота (не коммитится)

## Установка (локально)

Требуется Python 3.10 или новее.

1) Клонировать репозиторий и перейти в папку проекта:

```bash
git clone <REPO_URL>
cd <REPO_FOLDER>
```

2) Создать и активировать виртуальное окружение:

```bash
python3 -m venv venv
source venv/bin/activate
```

3) Установить зависимости:

```bash
pip install -r requirements.txt
```

## Запуск CLI

```bash
source venv/bin/activate
python ratings.py
```

Скрипт спросит:
- URL приложения (App Store или `https://play.google.com/store/apps/details?id=com.duolingo`)
- код страны (`us`, `ru`, `de`, ...)
- язык отзывов для Google Play (`en`, `ru`, `de`, `tr`, ...; по умолчанию `en`)
- рейтинг (`1..5` или `all`)

При первом запуске после обновления установи зависимости: `python -m pip install -r requirements.txt`.

## Массовая выгрузка

App Store (прежняя команда работает):

```bash
python bulk_reviews.py --ids 6746055015,6760271556 --countries us,de,ru --out data/appstore
```

Google Play (в `--ids` указываются package ID или ссылки через запятую):

```bash
python bulk_reviews.py --store googleplay --ids com.duolingo --countries ru,kz --lang ru --rating 1 --out data/googleplay-ru
```

Необязательный `--max-reviews 1000` ограничивает число отзывов на приложение и страну; по умолчанию лимита нет. `--rating all` собирает все оценки. Сначала загружаются самые свежие отзывы.

В выходной папке создаются `reviews.json`, `reviews.csv` и `ratings.json` (название, число оценок, средний балл). Повторный запуск в ту же папку перезаписывает эти файлы; для разных выгрузок используй разные папки. Google Play добавляет поле `language`; поле `title` пустое, поскольку отдельного заголовка у этих отзывов нет.

## Запуск Telegram-бота (локально)

1) Создать `.env` в корне проекта:

```env
BOT_TOKEN=ваш_токен_бота
```

2) Запустить:

```bash
source venv/bin/activate
python bot.py
```

В Telegram:
- `/start`
- отправить ссылку App Store или Google Play
- нажать **«Скачать все отзывы»** — сразу начинается сбор по всем странам и языкам, с оценками 1–5 и без фильтра по датам
- либо нажать **«Настроить»**, изменить только нужные параметры и выбрать **«Скачать с этими настройками»**
- получить Markdown-файлы с уникальными отзывами и `report.json` с охватом и ошибками

По умолчанию страна, язык и оценки равны `all`. Фильтры независимы: например, оценка 1 сохраняет все страны и языки. Выбор страны не ограничивает языки. После изменения параметра бот возвращается в меню настроек, а не задаёт следующий обязательный вопрос. `Назад` из редактирования сохраняет прежние значения; `Назад` из меню настроек возвращает основной режим и сбрасывает фильтры.

`hl`, `gl` и регион в присланной ссылке не ограничивают основной режим «все». При необходимости параметры выбираются в настройках. `all` возвращает все страны/языки/оценки; для иврита можно ввести `he` или `iw`.

**Охват и длительность.** Каталог от 30.10.2026 содержит 175 стран App Store, 250 региональных кодов Google и 129 языковых кодов Google Play, включая региональные варианты и базовые коды. Основной режим Google Play обходит полную сетку — 32 250 сочетаний; совпадение первых страниц не используется как повод пропускать остальные страны. Это может занять несколько часов и дольше для популярных приложений. В каталоге Google есть территории, где конкретное приложение или выдача могут быть недоступны; код региона сам по себе не гарантирует доступность. Источники: [каталог регионов Google](https://play.google.com/supported-locations?hl=en), [языки Google Play](https://support.google.com/googleplay/android-developer/answer/9844778?hl=en), [страны App Store](https://developer.apple.com/help/app-store-connect/reference/app-information/app-store-localizations/).

У Apple RSS нет отдельного фильтра языка: загружаются все языки каждой страны, максимум 10 страниц на страну. «Все» означает все доступные отзывы в пределах публичных интерфейсов и нашего каталога, а не гарантированно полный исторический архив.

`/status` показывает прогресс; исходное сообщение обновляется каждые 30 секунд при изменениях. `/stop` и `/cancel` во время загрузки останавливают сбор после текущих запросов и отправляют частичный результат. До завершения этой выгрузки повторный `/start` не запускает ещё одну. Вне загрузки `/cancel` просто сбрасывает диалог.

Ошибки не считаются пустой выдачей: они записываются в `report.json`, результат отмечается как частичный. После 12 последовательных ошибок сбор автоматически останавливается и сохраняет полученные данные. Отзывы хранятся во временной SQLite-базе, повторяющиеся ID объединяются с сохранением стран/языков запросов. Большие выгрузки делятся на Markdown-файлы примерно по 20 МБ. Перезапуск процесса прерывает задания — автоматического возобновления после перезапуска пока нет.

После обновления кода перезапусти процесс бота. Проверки без подключения к Telegram: `python -m unittest -v test_googleplay test_bot test_review_archive`.


## Примечания

- Apple RSS-API отдаёт доступный набор отзывов для выбранной страны; скрипт скачивает всё, что отдаёт этот API.
- Google Play использует форматы неофициальной библиотеки [google-play-scraper](https://github.com/JoMingyu/google-play-scraper). Ключи и доступ к аккаунту разработчика не нужны. Загрузчик бота делает запросы с таймаутами и явным учётом ошибок; консольный загрузчик использует публичную функцию библиотеки, которая может завершить выдачу при сетевой ошибке. Полнота публичной выдачи не гарантируется.
- Для Google Play `country` — страна запроса, а не подтверждённая страна автора. Страна и язык задаются независимо; отзывы могут пересекаться между выгрузками. Внутри одного запроса дубликаты удаляются по `review_id`; между странами сохраняются для сравнения выдачи.
- Логи выводятся в консоль/панель хостинга и помогают понимать, сколько времени заняла загрузка и сколько отзывов скачано.
